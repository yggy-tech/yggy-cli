# yggy CLI

Command-line client for [yggy](https://yggy.tech).

```bash
yggy auth login
yggy use org
yggy use project
yggy documents upload ./report.pdf
yggy documents wait <id>
yggy query "what changed in Q4?"
```

This repository is synced from the yggy platform monorepo. Do not hand-edit sources here; open changes against the platform API or CLI sources upstream.
